# הספרייה שלי

[English](README.md) · **עברית** · [Русский](README.ru.md)

רשימת ספרים אישית ב-JavaScript: מוסיפים ספר עם ISBN, שם, מחבר ושנה, רואים את הספרים בטבלה עם סטטיסטיקה, וכל ספר חדש מתקבל בזיקוקים. ובנוסף שעון ומוזיקת רקע.
